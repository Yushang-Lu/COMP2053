# 实验报告 LaTeX 模板

在本目录运行 `bash build.sh`，使用 XeLaTeX 编译，输出到 `../report.pdf`。
也可以在 LaTeX 编辑器中打开 `main.tex`，选择 XeLaTeX。

- `main.tex`：正文的可编辑文字、表格线和版式；坐标使用 PDF 的 bp 单位，以页面左上角为原点。
- `assets/cover.pdf`：从 `../../resource/数字逻辑设计实验报告模板2026秋_template.pdf` 提取的原始第 1 页，保持矢量和文字，不重排封面。
- `.build/`：编译辅助文件，已加入 Git 忽略规则。

输出共 4 页，对应原模板第 1、3、4、5 页。原第 2 页已删除；后续页面的红字、蓝字和示例模块图已删除，黑色标题、黑色说明、表格边框、分页和留白保留。

正文沿用原模板的仿宋字形，页眉使用宋体；优先使用本机 WPS 的字体，其他环境回退到 TeX Live 自带的 Fandol 字体。西文优先使用 Times New Roman，缺失时使用 TeX Gyre Termes。不同字体环境可能造成细微字形差异，封面始终保留原样。

正文可在对应注释处使用 `\ReportContent{左边距}{顶部坐标}{宽度}{内容}` 填写。当前是固定版式复刻，填写长报告时需要自行调整表格高度或增加页面。
