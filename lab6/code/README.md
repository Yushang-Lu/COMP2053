# Lab6 基础题 · EGO1

仅实现 UART 收发基础题，不包含计算器、打地鼠或矩阵键盘。依据本地课件 `../resource/lab6-综合实验.pdf` 和 2026-11-12 下载的网站镜像；没有改动课件、报告或其他实验。

## 个人信息

用户已确认第五组，`top.v` 的 `GROUP_ID` 已设为 `"05"`。`STUDENT_ID` 沿用此前实验的 `"2025310599"`。

每次发送 13 个 ASCII 字符 `05+2025310599`：两位组别、一个字面量 `+`、十位学号。不带 `hitsz`，也不附加回车换行。`top_tb.v` 使用相同组别和字符串进行测试。

## 功能和模块

| 文件 | 职责 |
| --- | --- |
| `top.v` | 顶层，仅声明连线、传递参数和例化子模块 |
| `key_press.v` | S2 两级同步、20 ms 稳定消抖、按下产生一拍脉冲 |
| `message_sender.v` | 按键触发整串发送；按实际发送完成脉冲累计两位 BCD 计数 |
| `uart_send.v` | 三段式 UART 发送状态机；基于 Lab5 实现，增加完成信号 |
| `uart_recv.v` | 输入两级同步；三段式 IDLE、START、DATA、STOP 接收状态机 |
| `receive_display.v` | ASCII 转十六进制数码；保存最近六个有效字符及位使能 |
| `segment_scan.v` | 八位动态扫描，控制 EGO1 两组独立段选 |
| `pin.xdc` | EGO1 引脚和 100 MHz 时钟约束 |
| `uart_recv_tb.v` | 网站官方十组测试，测试内容未改动，仅补文件末尾换行 |
| `top_tb.v` | 加速整机自检，不是实物测试或报告截图 |

接收路径：`uart_rx → uart_recv → receive_display → segment_scan`。

发送路径：`button_s2 → key_press → message_sender → uart_send → uart_tx`；`uart_send.done` 返回发送控制器累计字符数，再送往数码管扫描模块。

### 接收和显示

- 串口采用 9600 baud、8 数据位、无校验、1 停止位、无流控；100 MHz 下每位 10416 拍。
- 在每个数据位中点采样，低位在先；停止位中点更新 `data`，`valid` 仅维持一拍。起始位中点已恢复高电平时放弃本次接收，停止位中点为低时不输出有效数据。
- 起始低电平被识别的那一拍也计入起始位计数，避免连续无间隔帧每帧累积一拍的接收偏移。
- DK5–DK0：显示最近六个有效字符，最新字符在 DK0，旧字符向高位移动。
- 支持 ASCII `0`–`9`、`A`–`F`，同时接受小写 `a`–`f`。其他字符（含回车、换行）忽略，不挤掉已有字符。
- 不足六个字符时关闭相应高位的位选和段选，不用数字 0 代替空白。收到字符 `0` 时，该位正常显示 0。
- 例如依次接收 `0A1b2F3`，六位显示从 `     0` 逐步变为 `A1b2F3`。七段数码管的 B、D 使用可辨识的小写 b、d 字形。
- DK7–DK6：累计发送字符数的十进制低两位，初始 `00`；发完一整串为 `13`，八串后为 `04`。

### 按键和发送

- S1：高有效异步复位，清空接收显示和发送计数，中断正在进行的收发，TX 回到空闲高电平；复位期间关闭数码管。
- S2：每次稳定按下触发一串，持续按住不重复发送；再次触发须先稳定松开。
- 字符起始间隔 2 ms，一帧约 1.0416 ms，满足字符串内字符间隔不超过 0.01 s。最后一帧完成后等待下一次按键，不自动循环。
- 发送期间不接收新的发送请求、不排队；接收通道独立，发送时仍能接收并更新显示。默认 20 ms 消抖下，稳定松开后再按下所需时间长于一整串的发送时间。
- 若串口软件因分包超时将一串拆成多行，可像 Lab5 一样将接收分包超时设为 100 ms；代码本身不发送换行符。

## EGO1 和 Vivado

器件沿用 `xc7a35tcsg324-1`。`clk` 接 P17，S1 复位接 R17，S2 接 R15；FPGA 接收 `uart_rx` 接 **N5**，FPGA 发送 `uart_tx` 接 **T4**。

串口引脚已核对 `../../lab1/resource/Ego1开发板硬件手册V2.pdf` 的印刷第 11 页（PDF 第 12 页）。手册的 UART_RX/T4 是转换芯片接收端，即 FPGA 发送端，不要按名称反接。数码管沿用 Lab4 的 EGO1 高有效段选和位选映射；未使用 Minisys 引脚。

1. 确认 `top.v` 中的组别 `"05"` 和学号 `"2025310599"`。
2. 将七个功能 `.v` 文件加入 Design Sources，设计顶层设为 `top`。不要把测试文件加入综合，也不要同时加入 Lab4/Lab5 的同名模块。
3. 将 `pin.xdc` 加入 Constraints，保留 `create_clock`。
4. 将两个 `_tb.v` 文件加入 Simulation Sources。先将 `uart_recv_tb` 设为仿真顶层，Run All，确认十组测试通过；再切换 `top_tb` 检查整机。
5. 运行 Vivado Lint、综合、实现和 DRC，生成比特流并上板。`top_tb` 会覆盖参数以加速仿真，不要把其参数抄到实际顶层。
6. 串口软件选择 STR 模式，发送 `0123AF` 等字符测试接收；若使用 HEX 模式，字符 A 应发送 `41` 而不是 `0A`。按 S2 检查实际组别和学号，检查计数、长按和 S1 复位。
